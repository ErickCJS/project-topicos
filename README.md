# SGRS JLO — Sistema de Gestión de Residuos Sólidos

Aplicación web para la gestión de personal, vehículos y operaciones del servicio de limpieza pública de la Municipalidad Distrital de José Leonardo Ortiz.

## Tecnologías principales

- Laravel 12 y PHP 8.3.
- MySQL.
- Blade, JavaScript y Tailwind CSS.
- Docker para la construcción y despliegue de la aplicación web.
